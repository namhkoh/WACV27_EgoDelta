# Progress Freeze 2026-05-26

Branch: `redacted/robot-final`

## Current State

The harvesting stack now has a working IK/planning/execution path for the left-arm tomato harvest prefix, plus provisional gripper contact-frame support. A tomato0 grasp succeeded after applying the current visual contact-frame estimate, confirming that the main IK path can reach and execute a target when the gripper contact frame is modeled correctly.

The current blocker is calibration robustness. Static AprilTag repeat captures are stable at roughly millimeter scale, but broad cross-pose EEF AprilTag captures are not calibration-valid. The synced cross-pose set still produced impossible board-in-EEF variation and failed hand-eye fit validation, so it must not be used as a final calibration artifact.

## Calibration Facts

Static head-mount repeat after fixing the capture path was stable:

- Mean `board_origin_eef_m`: `[0.017442, -0.027959, -0.008193]`
- Std: `[0.000171, 0.000541, 0.000032]` m
- Range: `[0.000470, 0.001146, 0.000088]` m

Broad synced cross-pose captures were not stable:

- Accepted four-tag spread reached about `348 mm` in x, `89 mm` in y, and `290 mm` in z.
- Hand-eye fit on synced cross-pose captures produced about `75.4 mm` translation RMS and `0.526 rad` rotation RMS.

Conclusion: fixed-pose AprilTag detection is repeatable, but the current cross-pose calibration pipeline is not yet valid for a final gripper/contact calibration.

## Current Blocker

We still need a calibration-grade, target-general gripper contact-frame estimate. The provisional contact-frame JSON works for tomato0 but did not generalize cleanly to tomato1. The next calibration step should use a known reference board/contact point near the tomato workspace instead of relying on tomato geometry or broad arbitrary EEF poses.

## Next Suggested Step

Use simulation or a controlled physical reference to isolate the remaining issue:

- In Isaac Sim: visualize RBY1-A, the SDK/URDF tool frame, the modeled TCP, the contact-center offset, and a robot-frame 3D point.
- On hardware: perform contact calibration against a known AprilTag board point near the tomato workspace, then validate the resulting contact-frame transform on both tomato positions.
